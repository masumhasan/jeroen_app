# Jeroen Recipe App 📱

The core mobile experience for the Jeroen & Lisa. A beautiful, high-performance recipe application built with Private Recipe Data and OIPENAI

## 🌟 Features

- **AI-Powered Meal Plans**: Personalized weekly meal plans generated by OpenAI based on dietary preferences, allergies, and calorie goals.
- **Recipe Discovery**: Browse curated recipes with multi-category support (a recipe can belong to Lunch & Dinner).
- **Nutritional Insights**: Detailed breakdown of KCAL, KHD, Fats, Proteins, and Fiber for every recipe.
- **Meal Swapping**: Swap individual meals with alternative recipes or your own crowdsourced submissions.
- **Crowdsourced Recipes**: Users can submit their own recipes, which go through admin approval before appearing in meal plans.
- **Dietary Filtering**: Supports Vegan, Pescatarian, Gluten-free, Lactose-free, Keto, Paleo, and more — recipes are pre-filtered based on ingredients.
- **Allergy Safety**: Recipes containing user-specified allergens are automatically excluded from meal plans and swap suggestions.
- **Cooking Mode**: Step-by-step fullscreen cooking instructions.
- **Shopping List**: Auto-generated weekly shopping list grouped by store aisle categories.
- **Favourites**: Save and quickly access your favourite recipes.

## 🛠 Tech Stack

- **Framework**: React Native (Expo)
- **Navigation**: Expo Router (File-based)
- **Styling**: NativeWind / Tailwind CSS
- **Data Source**: Jeroen Backend (MongoDB)

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```
```bash
npx expo run:android
```
### 2. Start the App
```bash
npx expo start
```

### 3. Run on Emulator
- Press `a` for Android Emulator
- Press `i` for iOS Simulator
